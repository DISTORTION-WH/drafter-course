# НАЧАТЬ ЗДЕСЬ — новая project-first версия курса

Основной курс полностью переписан под один настоящий проект без выбрасываемых упражнений.

Читайте в таком порядке:

1. Откройте `project-first-course/README.md`.
2. Пройдите модули строго от `00-learning-contract.md` до `19-launch-graduation.md`.
3. Не переходите дальше, пока проверка и commit текущего модуля не выполнены.

Для Notion импортируйте одним архивом:

```text
exports/project-first-notion/Dota2-Analyzer-Project-First-NOTION.zip
```

Внутри архива 21 страница с префиксами `00`–`20`; `00_START_HERE` — единственное оглавление. Старые каталоги `course/` и `blueprint/` сохранены как архив предыдущей редакции, но не являются основным маршрутом обучения.
