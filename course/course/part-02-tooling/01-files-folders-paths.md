# Глава 1. Файлы, папки, расширения и пути

## 1. Файл

Файл — именованный набор данных на диске.

Примеры:

```text
match-analyzer.js
package.json
README.md
match-data.json
```

У файла есть:

- имя;
- расширение;
- содержимое;
- расположение;
- размер;
- права доступа;
- время изменения.

## 2. Расширение

Расширение — часть имени после последней точки.

```text
match-analyzer.js  → JavaScript
package.json       → JSON
README.md          → Markdown
.gitignore         → специальный файл без обычного расширения
```

Windows может скрывать расширения. Для разработки лучше включить их отображение в Проводнике: `Вид → Показать → Расширения имён файлов`.

Иначе можно случайно создать `index.js.txt`, который выглядит как `index.js`, но Node.js не воспринимает его как ожидаемый JavaScript-файл.

## 3. Папка

Папка группирует файлы и другие папки.

```text
dota-match-cli/
  src/
    index.js
  test/
    calculations.test.js
  package.json
```

Папка `dota-match-cli` здесь является корнем проекта. Корень проекта — верхняя папка, содержащая конфигурацию и исходный код конкретного приложения.

## 4. Дерево проекта

Структуру удобно читать как дерево:

```text
dota-match-cli
├── package.json
├── src
│   ├── index.js
│   ├── data
│   │   └── match.js
│   ├── domain
│   │   ├── calculations.js
│   │   ├── validation.js
│   │   └── match-report.js
│   └── presentation
│       └── print-report.js
└── test
    ├── calculations.test.js
    └── match-report.test.js
```

Отступ означает вложенность. `calculations.js` находится внутри `domain`, которая находится внутри `src`.

## 5. Путь

Путь описывает расположение файла.

Пример Windows:

```text
C:\Projects\dota-match-cli\src\index.js
```

Части:

- `C:` — диск;
- `Projects` — папка на диске;
- `dota-match-cli` — корень проекта;
- `src` — папка исходного кода;
- `index.js` — файл.

## 6. Абсолютный путь

Абсолютный путь начинается от корня файловой системы или диска:

```text
C:\Projects\dota-match-cli\src\index.js
```

Он не зависит от текущей папки терминала.

## 7. Относительный путь

Относительный путь считается от текущей рабочей папки.

Если терминал находится здесь:

```text
C:\Projects\dota-match-cli
```

то относительный путь к `index.js`:

```text
.\src\index.js
```

`.` означает текущую папку.

`..` означает родительскую папку:

```text
..\another-project
```

## 8. Текущая рабочая папка

Каждая команда терминала выполняется относительно current working directory — текущей рабочей папки.

Если вы запустили:

```powershell
node .\src\index.js
```

Node ищет `src\index.js` внутри текущей папки.

Большая часть ошибок «файл не найден» возникает не из-за отсутствия файла, а из-за неправильной текущей папки.

## 9. Пробелы в пути

Путь с пробелами заключайте в кавычки:

```powershell
Set-Location "C:\My Projects\dota-match-cli"
```

Без кавычек PowerShell может воспринять части пути как отдельные аргументы.

Для учебных проектов удобнее короткие имена без пробелов:

```text
dota-match-cli
dota-analytics
```

## 10. Разделители Windows и JavaScript imports

В PowerShell Windows часто используется обратный слеш:

```text
.\src\index.js
```

В JavaScript import обычно пишется через обычный слеш:

```js
import { calculateKda } from "./domain/calculations.js";
```

Не смешивайте синтаксис пути терминала и module specifier JavaScript.

## 11. Кодировка UTF-8

Файлы курса содержат русский текст. Сохраняйте исходники в UTF-8.

VS Code обычно использует UTF-8 по умолчанию. Текущая кодировка отображается в нижней панели редактора.

При неправильной кодировке вместо текста могут появиться нечитаемые символы.

## 12. Концы строк

Windows традиционно использует `CRLF`, Linux — `LF`. Современные инструменты умеют работать с обоими вариантами.

Важно не вручную переключать окончания строк без причины. Позже Git и formatter будут поддерживать единообразие проекта.

## 13. Скрытые и конфигурационные файлы

Примеры:

```text
.gitignore
.env
.editorconfig
```

Точка в начале имени на Unix-подобных системах означает скрытый файл. На Windows поведение отображения зависит от программы.

`.env` может содержать секреты и не должен попадать в публичный repository.

## 14. Имена файлов

Для JavaScript-проекта используйте понятные имена:

```text
calculations.js
match-report.js
print-report.js
```

Не используйте:

```text
file1.js
new.js
final-final-2.js
helpers-everything.js
```

Имя описывает ответственность файла.

## 15. Упражнения

- `test/calculations.test.js`.

### Упражнение 2

### Упражнение 3

Объясните разницу:

```text
C:\Projects\dota-match-cli\src\index.js
.\src\index.js
```

### Упражнение 4

Объясните, почему файл `index.js.txt` является проблемой.

## Definition of Done

- Вы отличаете файл, папку и расширение.
- Вы понимаете корень проекта.
- Вы различаете абсолютный и относительный путь.
- Вы знаете значения `.` и `..`.
- Вы понимаете роль текущей рабочей папки.
- Вы умеете читать дерево проекта.
