# Часть 1. Основы программирования

## Цель

Научиться читать и писать небольшие программы на JavaScript без фреймворков и базы данных.

К концу части вы создадите консольный анализатор одного матча Dota 2. Он будет:

- хранить игроков в массиве;
- хранить статистику игрока в объекте;
- проверять значения;
- рассчитывать KDA;
- определять результат игрока;
- группировать игроков по командам;
- считать командные суммы и средние значения;
- сортировать игроков;
- корректно сообщать об ошибочных данных.

## Как проходить

Рекомендуемый порядок для каждой главы:

1. Прочитать объяснение.
2. Набрать каждый пример вручную.
3. До запуска сказать, какой будет результат.
4. Изменить пример.
5. Выполнить упражнения.
6. Проверить Definition of Done.

## Где выполнять первые примеры

До главы об инструментах используйте консоль браузера:

1. Откройте Chrome или Edge.
2. Нажмите `F12`.
3. Выберите вкладку `Console`.
4. Введите `2 + 2`.
5. Нажмите Enter.

Браузер должен вывести `4`.

Если браузер показывает предупреждение о вставке кода, не вставляйте большие неизвестные фрагменты. Примеры курса лучше печатать вручную.

## Итоговый контроль

Часть завершена, если вы без копирования можете написать функцию:

```js
function calculateKda(kills, deaths, assists) {
  // ваша реализация
}
```

и объяснить:

- откуда приходят `kills`, `deaths`, `assists`;
- где они доступны;
- зачем нужен `return`;
- что произойдёт при `deaths = 0`;
- чем функция отличается от результата её вызова.
