# Глава 2. PowerShell и командная строка

## 1. Что такое терминал

Терминал — текстовый интерфейс для запуска программ и управления файлами.

PowerShell — оболочка Windows, которая читает введённые команды, выполняет их и показывает результат.

Пример приглашения:

```text
PS C:\Projects\dota-match-cli>
```

Часть до `>` показывает текущую папку. Текст после `>` вводите вы.

## 2. Как открыть PowerShell

Варианты:

- открыть Windows Terminal и выбрать PowerShell;
- открыть PowerShell через меню Пуск;
- в VS Code выбрать `Terminal → New Terminal`.

В курсе предпочтителен встроенный терминал VS Code: редактор и команда работают с одной папкой проекта.

## 3. Команда, аргумент и параметр

```powershell
Get-ChildItem -Force .\src
```

Здесь:

- `Get-ChildItem` — команда;
- `-Force` — именованный параметр;
- `.\src` — аргумент-путь.

PowerShell-команды часто называются `Глагол-Существительное`:

```text
Get-Location
Set-Location
Get-ChildItem
New-Item
Get-Content
```

## 4. Узнать текущую папку

```powershell
Get-Location
```

Короткий знакомый аналог:

```powershell
pwd
```

В курсе показываются полные имена PowerShell-команд, потому что они лучше объясняют действие.

## 5. Показать содержимое папки

```powershell
Get-ChildItem
```

Показать также скрытые элементы:

```powershell
Get-ChildItem -Force
```

Показать конкретную папку:

```powershell
Get-ChildItem .\src
```

## 6. Перейти в папку

```powershell
Set-Location C:\Projects
```

Относительный переход:

```powershell
Set-Location .\dota-match-cli
```

Вернуться на уровень выше:

```powershell
Set-Location ..
```

После перехода всегда можно проверить:

```powershell
Get-Location
Get-ChildItem
```

## 7. Автодополнение

Введите часть имени и нажмите `Tab`:

```text
Set-Location .\dota-m<Tab>
```

PowerShell дополнит существующий путь. Это быстрее и уменьшает количество опечаток.

## 8. Создать папку

```powershell
New-Item -ItemType Directory -Path .\dota-match-cli
```

Перейти в неё:

```powershell
Set-Location .\dota-match-cli
```

Создать вложенные папки по очереди:

```powershell
New-Item -ItemType Directory -Path .\src
New-Item -ItemType Directory -Path .\test
```

## 9. Создать пустой файл

```powershell
New-Item -ItemType File -Path .\src\index.js
```

Обычно содержимое исходников удобнее писать в VS Code, а не командами терминала.

## 10. Прочитать текстовый файл

```powershell
Get-Content .\src\index.js
```

Прочитать целиком как одну строку:

```powershell
Get-Content -Raw .\package.json
```

## 11. Копирование и перемещение

```powershell
Copy-Item .\src\index.js .\src\index-backup.js
```

```powershell
Move-Item .\src\index-backup.js .\src\old-index.js
```

Перед операцией проверьте существование источника и папку назначения.

## 12. Удаление: правило осторожности

Удаление через терминал может не использовать Корзину. На начальном этапе удаляйте файлы через Проводник или Explorer VS Code.

Не копируйте неизвестные команды с `Remove-Item`, особенно с `-Recurse`, `-Force`, wildcard `*` или вычисляемым путём.

Перед любой потенциально разрушительной командой:

1. Выполните `Get-Location`.
2. Выведите целевой путь.
3. Убедитесь, что это папка проекта.
4. Проверьте содержимое через `Get-ChildItem`.
5. Только затем решайте, нужна ли операция.

## 13. Остановить программу

Если программа долго работает или запущен сервер:

```text
Ctrl+C
```

Это отправляет процессу сигнал остановки.

Если вы случайно создали бесконечный цикл, `Ctrl+C` — первое действие.

## 14. Очистить экран

```powershell
Clear-Host
```

Это не удаляет файлы и не стирает историю команд, а только очищает видимую область терминала.

## 15. История команд

Клавиши ↑ и ↓ показывают ранее введённые команды. Не набирайте длинную команду заново, если нужно изменить один аргумент.

## 16. Кавычки

Для путей с пробелами:

```powershell
Set-Location "C:\My Projects\dota-match-cli"
```

Одинарные кавычки в PowerShell обычно не подставляют переменные, двойные могут подставлять. До изучения переменных shell используйте кавычки только для явных путей и не составляйте разрушительные команды из строк.

## 17. Результат команды и код завершения

Команда может:

- завершиться успешно;
- вернуть понятную ошибку;
- запустить долгоживущий процесс;
- ожидать ввода.

Читайте весь вывод. Красный текст не всегда означает повреждение системы: чаще это описание неверного пути, неизвестной команды или отсутствующего файла.

## 18. Частые ошибки

### Неправильная папка

```text
Cannot find path ... because it does not exist
```

Проверьте `Get-Location` и `Get-ChildItem`.

### Пропущены кавычки

Путь с пробелами разделился на аргументы.

### Опечатка в имени

Используйте `Tab` для дополнения.

### Команда не найдена

```text
The term 'node' is not recognized...
```

Программа не установлена или её папка отсутствует в `PATH`. Это будет разобрано в следующей главе.

## 19. Лабораторное упражнение

В безопасной учебной папке создайте структуру:

```text
dota-tools-practice/
  src/
    index.js
  test/
```

Порядок:

1. Перейдите в выбранную папку для проектов.
2. Проверьте `Get-Location`.
3. Создайте `dota-tools-practice`.
4. Перейдите внутрь.
5. Создайте `src` и `test`.
6. Создайте пустой `src\index.js`.
7. Выведите дерево через несколько `Get-ChildItem`.
8. Откройте папку в VS Code после установки редактора.

## Definition of Done

- Вы умеете узнать текущую папку.
- Вы умеете показать содержимое папки.
- Вы переходите по абсолютному и относительному пути.
- Вы используете `Tab`.
- Вы создаёте папку и пустой файл.
- Вы понимаете назначение `Ctrl+C`.
- Вы не запускаете команды удаления, не проверив точный путь.
