# Dota History CLI

Учебный анализатор истории профессиональных матчей Dota 2 для части 3 курса.

## Что демонстрирует

- асинхронное чтение файла через `node:fs/promises`;
- безопасный parsing JSON;
- validation недоверенных данных;
- группировку через `Map`;
- уникальные значения через `Set`;
- неизменяемые преобразования массивов;
- разделение I/O, domain и presentation;
- тесты встроенным `node:test`.

Внешних dependencies нет, поэтому `npm install` не требуется.

## Требования

- Node.js 22 LTS или новее;
- терминал, открытый в этой директории.

## Запуск

С демонстрационными данными:

```powershell
npm start
```

Или напрямую:

```powershell
node src/index.js
```

С собственным JSON-файлом:

```powershell
node src/index.js C:\путь\к\matches.json
```

Путь без буквы диска считается относительно текущей директории терминала.

## Тесты

```powershell
npm test
```

Или:

```powershell
node --test
```

## Намеренная ошибка

```powershell
node src/index.js missing.json
```

Команда должна вывести контекст ошибки и вернуть ненулевой exit code.

## Формат входа

Корневое значение — непустой массив. Каждый матч должен иметь статус `finished`, ровно 10 игроков и по 5 игроков каждой стороны. Полный пример находится в [data/matches.json](data/matches.json.md).

Проект использует вымышленные команды, игроков, match ID и статистику. Это учебные данные, а не сведения о реальных матчах.
