# Как импортировать курс

## Вариант 1 — Notion

Используйте `Dota2-Analyzer-Course-NOTION.zip`.

1. Откройте Notion в desktop/web.
2. Выберите `Settings → Import → ZIP` либо введите `/zip` и выберите `Convert Zip to pages`.
3. Загрузите архив.
4. Откройте страницу `00-НАЧАТЬ-ЗДЕСЬ`.
5. В базе `КУРС-ПРОГРЕСС` преобразуйте `Статус` в Status/Select, отсортируйте по `Порядок` и создайте Board view.

Не импортируйте один архив повторно в тот же раздел: CSV imports добавляют строки и могут создать дубликаты. Если полный ZIP импортировался частично, сначала проверьте уже созданные страницы. Затем удалите неполный импорт или используйте четыре запасных тома по порядку.

Notion не импортирует Markdown anchor links. Для переходов по заголовкам используйте Table of Contents и поиск.

## Вариант 2 — Obsidian

Распакуйте `Dota2-Analyzer-Course-OBSIDIAN.zip`, затем в Obsidian выберите `Open folder as vault`. Это лучший локальный вариант: сохраняются папки, Markdown-ссылки и исходные файлы кода.

## Вариант 3 — один файл

Откройте `single-file/DOTA2-ANALYZER-ПОЛНЫЙ-КУРС.md` в VS Code, Typora, Obsidian или импортируйте в Notion как Text & Markdown. Этот вариант проще, но у него нет отдельных страниц и базы прогресса.

## Как вести прогресс

- `Не начато` — главу ещё не открывали;
- `В процессе` — читаете и выполняете практику;
- `На повторение` — результат работает, но вы пока не можете объяснить его без подсказки;
- `Готово` — практика и Definition of Done выполнены, код объясняется своими словами.

Не отмечайте главу завершённой только после чтения. Нужны команды, код, тесты и доказательство результата.
