# Dota Analyzer: project-first курс для человека без опыта программирования

> Импортируйте всю папку или ZIP целиком. Имена файлов имеют числовые префиксы, поэтому страницы сортируются строго от 00 до 20. Название страницы берётся из первого заголовка внутри файла.

## Что изменено

Это новая основная версия курса. В ней нет отдельных упражнений вроде «создайте переменную `age`», калькуляторов, вымышленных каталогов и React-песочницы, которые потом выбрасываются.

С первой главы вы работаете только в одном репозитории `dota-analyzer`. Каждый написанный файл либо остаётся в итоговом приложении, либо является его тестом, конфигурацией или миграцией.

Формат каждой главы:

1. какой настоящий результат добавляется в приложение;
2. какие реальные файлы создаются или меняются;
3. готовый рабочий пример;
4. разбор переменных, функций, типов и каждой важной строки;
5. аналогичная задача, которую вы пишете сами в этом же проекте;
6. точные имена файлов, переменных и функций для вашей задачи;
7. эталон решения после самостоятельной попытки;
8. команды проверки и ожидаемый результат;
9. Git commit, фиксирующий работающий этап.

## Что получится

```text
React Native приложение
  -> собственный Node.js API
  -> PostgreSQL
  -> worker импорта профессиональных матчей
  -> матчи, команды, игроки и турниры
  -> аналитика героев по патчу и периоду
  -> поиск, Steam login, watchlist и push
  -> тесты и наблюдаемость
  -> AWS production
  -> Google Play / TestFlight
  -> freemium и Pro-подписка
```

## Единый стек проекта

Курс использует только технологии итогового приложения:

- Node.js 24 LTS;
- TypeScript;
- pnpm workspace;
- NestJS с Fastify;
- PostgreSQL и Prisma;
- Redis и BullMQ;
- Zod для внешних данных и конфигурации;
- React Native, Expo SDK 56 и Expo Router;
- TanStack Query;
- SecureStore;
- Vitest, Supertest и React Native Testing Library;
- Docker Compose локально;
- AWS CDK, ECS Fargate, RDS, ElastiCache, S3 и CloudFront;
- EAS Build, Google Play и App Store Connect;
- RevenueCat как практический слой над StoreKit/Google Play Billing;
- CloudWatch и Sentry.

Версии зафиксированы на дату редакции курса. Перед production upgrade вы не меняете их вслепую: сначала отдельная ветка, tests и staging.

## Что больше не является обязательной частью

Replay parsing, Java/Clarity, ClickHouse и ML не входят в первый проект. Они добавляются только после запуска, если реальные пользователи и нагрузка доказали необходимость. Иначе это лишние месяцы работы и расходы.

## Коммерческая граница

Техническая доступность данных не означает право продавать продукт на их основе. До публичной оплаты должны быть письменно проверены условия выбранного data provider, хранение и переработка данных, изображения, названия и логотипы. Если права не подтверждены, приложение остаётся закрытой учебной beta на разрешённых данных.
