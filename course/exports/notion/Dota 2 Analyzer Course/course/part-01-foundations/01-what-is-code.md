# Глава 1. Что такое код

## 1. Программа

Программа — это набор инструкций, которые компьютер выполняет в определённом порядке.

Например, задача «показать KDA игрока» состоит из шагов:

1. Получить число убийств.
2. Получить число смертей.
3. Получить число assists.
4. Выбрать формулу.
5. Выполнить вычисление.
6. Показать результат.

Такое пошаговое описание решения называется алгоритмом.

## 2. Исходный код

Исходный код — текст, написанный на языке программирования. JavaScript — один из таких языков.

```js
const kills = 10;
const deaths = 2;
const assists = 8;
const kda = (kills + assists) / deaths;

console.log(kda);
```

Компьютер не понимает слова `kills` как понятие Dota 2. Это имя выбрал программист. JavaScript понимает правила записи:

- `const` создаёт именованную переменную;
- `=` связывает имя со значением;
- `+` складывает;
- `/` делит;
- `console.log` выводит значение;
- `;` завершает инструкцию.

## 3. Инструкция и выражение

Выражение создаёт значение:

```js
2 + 3
```

Результат выражения — `5`.

Инструкция говорит выполнить действие:

```js
const total = 2 + 3;
```

Здесь JavaScript вычисляет выражение `2 + 3` и сохраняет результат под именем `total`.

## 4. Порядок выполнения

Обычный код выполняется сверху вниз:

```js
console.log("Первое сообщение");
console.log("Второе сообщение");
console.log("Третье сообщение");
```

Если переставить строки, изменится порядок вывода.

Позже вы узнаете об асинхронных операциях, где ожидание сети меняет привычную картину. Пока считайте, что строка выше выполняется раньше строки ниже.

## 5. Синтаксис

Синтаксис — правила записи языка.

Правильно:

```js
console.log("Dota 2");
```

Неправильно:

```js
console.log("Dota 2);
```

Во втором примере нет закрывающей кавычки. JavaScript не может определить, где заканчивается текст.

Ошибка синтаксиса похожа на предложение без закрытой скобки или кавычки: смысл может быть очевиден человеку, но формальные правила нарушены.

## 6. Значение и представление

Число `10` и текст `"10"` выглядят похоже, но являются разными значениями.

```js
console.log(10 + 5);       // 15
console.log("10" + "5"); // "105"
```

В первом случае выполняется арифметическое сложение. Во втором — соединение текста.

Тип значения влияет на то, какие операции выполняет программа.

## 7. Комментарии

Комментарий предназначен для человека и не выполняется.

Однострочный комментарий:

```js
// Количество убийств игрока
const kills = 10;
```

Многострочный комментарий:

```js
/*
  Эта формула временная.
  Позже мы отдельно обработаем deaths = 0.
*/
const kda = (kills + assists) / deaths;
```

Не комментируйте очевидное:

```js
// Создаём kills со значением 10
const kills = 10;
```

Лучше объяснять причину решения:

```js
// Ноль смертей обрабатываем отдельно, чтобы рейтинг оставался конечным числом.
```

## 8. Первая мини-программа

Наберите в консоли браузера:

```js
const playerName = "Yatoro";
const heroName = "Juggernaut";
const kills = 12;
const deaths = 3;
const assists = 9;
const kda = (kills + assists) / deaths;

console.log(playerName);
console.log(heroName);
console.log(kda);
```

До запуска ответьте:

- сколько раз будет вызван `console.log`;
- в каком порядке появятся значения;
- чему равен `kda`.

Теперь измените значения так, чтобы KDA стал равен `4`.

## 9. Частые ошибки новичка

### Разные кавычки

```js
const name = "Yatoro';
```

Открывающая и закрывающая кавычки должны соответствовать друг другу.

### Разный регистр

```js
const playerName = "Yatoro";
console.log(playername);
```

`playerName` и `playername` — разные имена.

### Код написан после использования

```js
console.log(kills);
const kills = 10;
```

В момент первой строки переменная ещё не инициализирована.

### Чтение нескольких ошибок как одной

Исправляйте первую ошибку, запускайте снова и только затем переходите к следующей. Одна пропущенная скобка может породить много дополнительных сообщений.

## Definition of Done

- Вы можете открыть консоль браузера и выполнить код.
- Вы понимаете, что код выполняется по инструкциям.
- Вы отличаете число от текста.
- Вы умеете вывести значение через `console.log`.
- Вы не пугаетесь синтаксической ошибки и ищете незакрытые кавычки и скобки.
